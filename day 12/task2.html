Floating Image Beside Text

Floating an image beside text allows for more attractive and readable page layouts. In this example, the image is floated to the left, so the text flows neatly around it. This is a common technique used in articles, blogs, and news websites where images are placed next to paragraphs to support the written content visually.

However, when using float, sometimes the parent container might collapse because floated elements are taken out of the normal document flow. To fix this, we can apply a clearfix — a CSS method that ensures the parent element expands to contain its floated children. This keeps the layout structured and avoids overlapping content.
